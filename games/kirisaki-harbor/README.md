# 雾岬渔港

低多边形风格的 3D 渔港小镇沙盘，单文件 `index.html`，直接打开即可运行。

## 内容

- **沙盘底座**：陆地一侧切开能看到草皮、土层、黏土和岩层；海的一侧是半透明水体，能看到海底的沙、水草、石头和礁石的水下部分。
- **港口**：岸壁带黄黑警示线和系船柱，停着大小五条船（随浪起伏），一条小船在港湾里绕圈；右侧是防波堤、消波块和红白灯塔。
- **小镇**：主干道和通往车站的支路、斑马线、电线杆和电线，超市、鲜鱼市场、港务所、镇公所、民房、樱花树；后山有梯田和电车隧道。
- **会动的**：海面波浪、车流、在车站和隧道之间往返的电车、海鸥、灯塔光束、风向袋、水草。
- **控制面板**（右下角）：
  - 视角：全景 / 港口 / 灯塔 / 截面 / 俯视，另有自动环绕
  - 天气：晴 / 雨 / 太阳雨（太阳雨出彩虹，下雨时水面有涟漪）
  - 时间：午后 / 黄昏 / 夜晚（入夜后窗户、路灯、自动售货机会亮）

## 技术

- Three.js r128（cdnjs）+ OrbitControls（jsDelivr）。
- 所有几何体和招牌文字都由代码生成（招牌用 Canvas 贴图），没有外部模型或图片。
- 随机数用固定种子，每次打开布局一致。
