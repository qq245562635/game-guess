# bg_city v2：地面透视返工

依据：dbfc39a 的 ASSETS.md「远景」及 reference/bg_city-ground-grid.png。替换 `assets/bg_city.png` **及** `assets/bg_city.jpg`，两者均为 2048×3328、不透明、同一画布；不修改游戏代码、镜头、办公室位置或 assets/index.json。

## 这次修正

v1 只检验了背景覆盖和房间锚点，没有核对外部路缘的斜率，导致楔形空隙。v2 以底稿中的同一等角坐标系重建地面：

```
x = 480 + 64 × (u - v)
y = 704 + 32 × (u + v)
```

| 边界 | 前角（逻辑坐标） | 网格 |
|---|---|---|
| 地板前缘 / 人行道内缘 | (544,1120) | u=7、v=6 |
| 1 格人行道外缘 | (544,1184) | u=8、v=7 |
| 0.5 格树篱外缘 | (544,1216) | u=8.5、v=7.5 |
| 3 格马路外缘 | (544,1408) | u=11.5、v=10.5 |

人行道内缘直接使用地板前缘的同一条线，未留额外底色带。所有新地面轮廓、铺砖接缝、路缘和斑马线均由网格坐标生成，398 条几何线段斜率验证为 ±0.5。前角保留通行缺口。

不是改游戏地板来迎合远景。采用已有纸纹、生成的透明树篱素材及原图汽车/前景美术，按确定的网格烘焙到背景。最初整图生成稿仍有透视偏差，已弃用，没有作为最终交付。

天空、太阳、云、远山和远处建筑从 v1 原位保留。PNG 对地面返工区域之外逐像素比较通过；JPG 由同一最终 PNG 重新编码，存在正常有损压缩差异。

- `previews/bg_city-v2-mobile-390x844.png`、`bg_city-v2-mobile-360x640.png`、`bg_city-v2-mobile-360x800.png`：无辅助线的实际游戏截图。
