# UI 补图：弹窗「确定」立体按钮（给 Codex）

第一批 UI（UI-BATCH-01）只切了底栏按钮，弹窗里的「确定」没有单图。现在游戏里先用 CSS 仿出了效果，请补正式素材，到货后同名放进 `assets/ui/`，Claude 换成贴图。

## 依据

- 已确认的效果稿：`previews/ui-menu-project-v1.png`，右半张「新企划书」底部的「确定」。
- 按钮放大截图：`reference/dlg-btn-ref.png`（从效果稿裁出放大 3 倍，**只作参考，不要直接用**，边缘有糊）。
- 当前 CSS 仿制效果（可对照）：在游戏里打开 菜单 → 开发 → 新企划，看底部「确定」。

## 要出的图

| key | 逻辑尺寸 | 交付像素 | 九宫格（上,右,下,左） | 说明 |
|---|---|---|---|---|
| ui_dlg_btn | 200×64 | 400×128 | 16,16,20,16 | 常态。**一直显示**，不是按下才出现 |
| ui_dlg_btn_down | 200×64 | 400×128 | 16,16,20,16 | 按下 / 选中 |
| ui_dlg_btn_off | 200×64 | 400×128 | 16,16,20,16 | 不可点（灰化），用于「确定」被禁用时 |

九宫格下边比上边大，是为了把底部的厚度和投影整块留在不拉伸区。按钮会横向拉伸到 200～300 逻辑宽，请确认拉伸后中段没有纹理接缝。

## 外观（照效果稿）

- **形状**：圆角矩形，圆角约 10～12（逻辑像素）。
- **描边**：深青绿 `#075C63`，约 3 逻辑像素，和弹窗外框、表单行同色。
- **面**：浅黄绿纸面，上亮下暗（约 `#F4F8E4` → `#D2E4A6`），保留效果稿那种淡淡的纸纹，和米白面板同一质感。
- **立体感**（重点，用户明确要求）：
  - 顶部内侧一道白色高光；
  - 底部内侧略深的绿色唇边；
  - 描边下方有约 4～5 逻辑像素的深青绿「厚度」，再往下一圈很淡的柔和投影。
- **按下态**：同一轮廓整体下沉，厚度只剩约 1 像素、投影几乎消失，面色比常态深一档，顶部高光换成浅浅的内阴影。**按下态的外轮廓底边必须和常态对齐**（程序会把按钮下移 4 像素，图本身不要再整体位移）。
- **不可点**：同轮廓，面和描边去饱和、变浅灰，保留厚度但不要投影。

## 硬性要求

- 透明 PNG（RGBA），按 2 倍出图，三张轮廓完全一致、像素对齐。
- 图里**不要带字**，「确定」由程序渲染（深青 `#043E3D`，粗体 34）。中间文字区保持干净、没有高光斑。
- 投影要画在图内，透明边距尽量小；投影外缘不要被画布切掉。
- 非像素风，和第一批 UI 统一。
