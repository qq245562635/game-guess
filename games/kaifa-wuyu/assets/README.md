# 开发物语 · 第一批场景素材

10 张透明 PNG，均按 ASSETS.md 的 2 倍尺寸交付。index.json 是 key 数组，原型启动时会按 key 自动加载。metadata.json 记录 1x 尺寸、锚点、2:1 网格和四个桌子的格子坐标。不要去掉 PNG 的透明留白，也不要重新按可见内容裁切，否则锚点会失效。

地面、墙段、desk / desk_back 和 chair 可替换同名占位图。人物、老板桌、秘书前台、装饰、远景和 UI 单图在下一批；它们继续使用原型占位图。

完整交付说明、母版、概念稿、提示词及验证报告位于 ../art/，程序接入请先读 ../art/CLAUDE_HANDOFF.md。美术由内置 image_gen 生成，经过尺寸与投影规范化。此次没有修改玩法源码；上传后由原型现有加载器自动加载这些同名素材。
