## 接入

- UI 放在独立 `assets/ui/` 目录。不要将这些 key 合并到场景 assets/index.json；UI 由 DOM / UI 渲染层单独加载。
- 顶栏和信息栏 frame 已含米白底，可直接用。panel 是可选内层，避免把它盖到 frame 的圆角外。
- 所有文字、粉丝数、日期和金额由代码渲染。金币、日期闪烁圆点、分隔线、滚动条均独立。
- 以逻辑尺寸显示；不要把 PNG 的双倍像素尺寸当成布局尺寸。
- metadata.json 的 `nineSlice` 保留需求文档数值，顺序是上、右、下、左，单位是逻辑像素。
- **推荐使用 `safeNineSlice` 做实际切片**：母版圆角大于原文档边距，安全边距完整包住圆角；布局宽高不变。读取源图时将边距乘 2。例如主按钮文档边距为 14，保形边距为 16；顶栏保形边距为 22,24,22,24。
- `ui_bb_btn_down` 是同一轮廓的按下色阶；`ui_bb_btn_empty` 是同轮廓深青绿空槽。`ui_sidetab_back` 仅反转箭头，仍贴左边缘。
- 底栏是空白纸纹取样后镜像平铺的无控件底图，可横向平铺。透明把手已剔除母版底下的办公室和街道颜色。
- 面板/按钮中部用 #FDEED5 修复文字区，保留母版外缘；不把含文字的区域留在拉伸区。金币及橙色箭头使用母版像素分离。
