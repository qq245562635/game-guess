# 开发物语 · UI 美术需求（给 Codex）

布局已经定死，完全照《游戏发展国》的竖屏布局：**只换皮，不改位置和尺寸**。
可玩原型：`games/kaifa-wuyu/index.html`。每个界面状态的截图在 `docs/ui/`。
场景里的地板、家具、员工另见 `ASSETS.md`，本文件只管 UI。

## 通用规则

### Issue #16 验收补充（优先于本文旧规格）

「菜单展开 + 新企划书」以 [统一字体效果图](art/previews/ui-menu-project-v2.png) 为视觉标准，效果、尺寸与颜色优先于下面旧表格：保留扁平浅绿且居中的宽「确定」按钮；渠道数值格浅绿、类型/内容米白、方针白色；标题直接置于内容底色，不另加标题条。不要依旧的 `ui_dlg_title` 或 `ui_dlg_btn 200×64` 将此界面改回旧样式。

全套 UI 文字统一使用 **Noto Sans SC**（字重可变、字体族一致），包括标题、日期、金币数字、菜单、标签、数值与按钮。字体和可商用许可证见 [assets/fonts/README.md](assets/fonts/README.md)，排版交付说明见 [art/UI-MENU-PROJECT-V2.md](art/UI-MENU-PROJECT-V2.md)。新版效果图中的「电脑 / 500金」仍是待负责人确认的内容，本次不改，程序数据不按此回退。

- 设计分辨率 **720 宽**（高度随屏幕变，中间场景区伸缩）。下文尺寸都是 720 宽下的设计像素。
- 交付 **2 倍图**（尺寸 ×2），透明 PNG，文件名用下表的 key。
- 风格：以 Codex 第一版效果图为准（毛毡 / 纸感手作风，米白纸板面板，深青绿底栏，绿色选中）。全套统一。
- 九宫格的拉伸区用纯色或可平铺纹理，避免拉伸后纹理变形、缩小后出现摩尔纹。
- 能拉伸的框一律做 **九宫格**：表里「九宫格」一栏是四边不拉伸的宽度（上,右,下,左）。
- 按钮都要 **常态 / 按下** 两个状态；菜单项、选项行另有 **选中**。
- 文字由程序渲染，图里**不要带字**（图标里的符号除外）。

要求：

- 形象必须和场景里的员工是同一个人：发型、发色、衣服、配饰完全一致。对照图 `art/reference/staff-identity.png`（场景坐姿正 / 背面），原图在 `assets/char_<n>_front_a.png`。
- **站立、正面、全身**（场景里是坐姿，这里要站起来，补出下半身：深色裤子、鞋）。Q 版比例和场景一致，大约 2.5 头身。
- A 帧：自然站立、双手垂放或轻握。B 帧：同一姿势的小动作（比如抬一只手打招呼 / 握拳打气），**脚的位置和身体轮廓尽量不动**，交替时不能跳。
- 画布底部中心是脚底：脚底贴画布下边缘往上 4 像素（1x），人物左右居中。四个人用**同一个缩放**，身高差按场景里的比例来，最高的人头顶离画布顶约 6 像素。
- 透明底，不带地面影子（程序会画），不带文字。风格同场景人物（毛毡 / 纸感 / 手作）。
- 可选：老板 `ui_staff_boss_a/b`、秘书 `ui_staff_sec_a/b`，同规格，以后用于事件对话。
