# 开发物语

致敬《游戏发展国》的游戏公司经营。布局完全照原作竖屏，只换皮不改位置。

## 运行

浏览器直接打开 `index.html`。

## 当前范围（先定方向）

只做一条主线：

右下「菜单」→ 开发 → 新企划 → 新企划书（渠道 / 类型 / 内容 / 开发方针）→ 游戏方针 8 项 → 制作人卡片 → 「正在整理企划」负责人工作画面（逐次加点，结束可能触发事件：组合很新鲜 / 擅长类型 / 灵感爆发 / 太累）→ 回工位继续开发、员工冒点数 → 40% 选画面负责人、75% 选声音负责人（同样有工作画面） → 完成 → 渠道审核 → 媒体评分 → 每周销量（按渠道分成）。玩法细节见 `策划案-新企划.md`。

行动 → 宣传：有在售作品时才能宣传，花钱涨粉丝，在售作品接下来几周销量上涨（效果每周衰减，连续宣传边际递减）。

游戏杂志：每月第 1 周送来一期，翻页阅读后结算文章带的事件效果（流行加成、资金、粉丝、选择）；信息 → 游戏杂志 看往期。框架和事件字段见 `杂志系统.md`，现有事件只是示例。

标题画面：新游戏（先给公司命名）/ 读取游戏 / 纪录（名人堂和历代销量，跨存档保留）。系统 → 回到标题。

开发 → 委托开发：每月 3 个外包委托，要求某项能力的全员合计，做完按完成度拿报酬（不足一半、超额有奖金）。做委托时不能开新企划。

职员 → 招聘：四种招聘方式（网站 / 高校 / 猎头 / 粉丝推荐），应聘者卡片翻页录用；座位满（4 人）时先请一位离开。职员一览里点人也可以请他离开。

新企划选完制作人后给作品命名。

员工成长：开发 / 委托中每周、做负责人、培训都给经验，升级加能力和月薪；满 5 级可以在 职员 → 转职 换职业（制作人、硬件工程师、黑客，或转回基础职业）。

除 Bug：开发到 100% 还有 Bug 时可以选择继续修，除错中从「开发 → 新企划」随时喊停发售。

续作：新企划书「续作」一行，可选总分 24 以上的系列，类型内容沿用；发售初期卖得更好，但做多了创新打折。

年度游戏大赏：每年 3 月第 4 周评选本年度作品，按门槛颁奖（暂无对手作品）。信息 → 公司数据：累计成绩和历年收益。

其他菜单项（取得授权）先占位，点了由秘书提示「还在规划中」。

## 声音

音乐和音效全部用 WebAudio 现场合成（`src/audio.js`），不需要音频文件：平时一首轻 bossa，开发中换成明快的 pop；按钮、秘书说话、冒点数、评分滚动、大卖号角、销售入账等都有音效。「菜单 → 系统 → 声音」可分别开关。换正式音频的 key 和规格见 `AUDIO.md`，试听：`docs/audio-preview.mp3`（前 22 秒平时 BGM，接着开发中 BGM，最后是全部音效）。

## 美术

- UI：`UI需求.md`，各界面状态截图在 `docs/ui/`。
- 场景（地板、墙、家具、员工）：`ASSETS.md`。
- 场景图放进 `assets/` 并写 `assets/index.json`（key 数组）即可自动替换；UI 图交付后由程序接入。

## 目录

```
index.html          构建产物，单文件可玩版本
src/audio.js        音乐和音效（WebAudio 合成，可被 assets/audio/ 里的文件替换）
src/game.js         渲染、模拟、UI 逻辑
src/game.src.html   布局与样式，构建时内联 src/game.js
tools/build.py      生成 index.html（内联 audio.js + game.js）：python3 tools/build.py
策划案-新企划.md      新企划流程策划案（渠道/类型/内容/开发方针/方针/制作人）
杂志系统.md          游戏杂志 / 事件框架（出刊规则、事件字段、效果类型）
策划案-缺失功能.md    对照原作的缺失功能清单与优先级（标题画面、委托、招聘、续作……）
UI需求.md            给 Codex 的 UI 出图需求
ASSETS.md           给 Codex 的场景出图需求
AUDIO.md            音乐 / 音效清单与替换规格
docs/ui/            各界面状态截图
```
