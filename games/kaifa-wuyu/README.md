# 开发物语

致敬《游戏发展国》的游戏公司经营。当前进度：第一场景（办公室）+ 核心玩法循环。

## 运行

浏览器直接打开 `index.html`。

## 玩法

- 时间：1年4月起，4 周一月，每月发工资，每年 4 月年度结算；暂停 / 1× / 2× / 4×。
- 开发新作：平台 + 类型 + 题材 + 企划负责人；40% 选画面负责人，75% 选声音负责人。
- 员工每周产出趣味、创意、画面、声音和 Bug；完成后可继续调试或直接发售。
- 4 位评审打分（满分 40，≥32 进名人堂），销量每周衰减，受评分、粉丝、平台份额影响。
- 类型 × 题材相性（◎○△）发售后揭晓。
- 受托开发、招聘（6 工位）、培训、升级、体力与咖啡、研究解锁、平台授权、记录、本地存档。
- 操作：拖动平移，滚轮/双指缩放，双击复位，点员工看详情。

## 美术

全部是代码绘制的占位图，规格见 `ASSETS.md`。替换方式：

- 预览：游戏内「菜单 → 导入 PNG」或把图片拖进页面（文件名 = 素材 key）。
- 正式接入：图片放进 `assets/`，并写 `assets/index.json`（key 数组），启动时自动加载。

## 目录

```
index.html          构建产物，单文件可玩版本
src/game.js         游戏逻辑（渲染、模拟、UI）
src/game.src.html   页面模板与样式，构建时内联 src/game.js
tools/build.py      生成 index.html：python3 tools/build.py
ASSETS.md           给 Codex 的出图清单
```
