# 开发物语 · 游戏杂志系统

> 照原作「游戏杂志」：定期送来一期，玩家翻页阅读，读完后结算文章带的效果。
> 杂志是**事件的载体**：以后设计的事件，大多以「一篇文章 + 效果 / 选择」的形式出现。
> 本文只定框架和字段，现有事件都是**示例**，正式事件内容待设计。

---

## 1. 出刊规则

- 每月第 1 周检查一次，有稿才出刊（没有就跳过这个月）。
- 本期文章来源，按顺序：
  1. **推送稿**：程序在别处投进来的稿子（新作发售速报、事件链的后续），到期必上。
  2. **事件**：`MAG_EVENTS` 里满足条件的，按 `prio` 从高到低，掷 `chance`。
- 每期最多 `MAG_MAX = 4` 篇。没挤进去的一次性事件下个月还有机会。
- 出刊时时间暂停；如果正好有别的弹窗（发售、负责人选择等），等它关掉再出。
- 往期保留最近 12 期：菜单 → 信息 → 游戏杂志，只读，不重复结算。

## 2. 阅读界面（照原作截图）

```
┌ ◀   游戏杂志 1/3   ▶ ┐   标题条，只有 1 篇时不显示箭头
│ ┌──────────────────┐ │
│ │  游戏行业的动向  [图] │ │   栏目条：栏目名（或文章自定标题）+ 栏目图标
│ └──────────────────┘ │
│ ┌──────────────────┐ │
│ │   正文段落，首行缩进 │ │   正文纸
│ └──────────────────┘ │
└──────────────────────┘
底栏：左空槽，右「返回」= 合上杂志
```

- 点正文翻到下一页；◀ ▶ 循环翻页；「返回」随时合上。
- 合上后按文章顺序结算：**效果（fx）→ 秘书台词（say）→ 选择（ask）**。效果文字由秘书说出，如「收到 3,000 金。粉丝 +800。」

## 3. 栏目

| cat | 栏目名 | 用途 |
|---|---|---|
| trend | 游戏行业的动向 | 季节、市场流行 |
| news | 业界新闻 | 新作速报、渠道动态 |
| reader | 读者来信 | 对玩家作品的反馈 |
| special | 特别报道 | 获奖、大事件 |
| ad | 杂志社来信 | 带选择的商业事件 |

新增栏目：在 `MAG_CAT` 加一行，并请 Codex 出 `ui_mag_<cat>.png`。

## 4. 事件字段

```js
{
  id: 'rpg_boom',          // 唯一 id，存档里记已出现次数
  cat: 'trend',            // 栏目
  title: '',               // 可选，替换栏目条上的栏目名
  text: [...] | () => [...],  // 段落数组；函数形式可以引用玩家作品名等
  prio: 0,                 // 越大越先上，季节专栏 7，推送稿固定最高
  chance: 1,               // 满足条件后每期出现的概率
  once: true,              // false = 可重复出现
  cd: 0,                   // 可重复事件的冷却（月）
  month: [7],              // 只在这些月份出现
  when: () => bool,        // 其他条件（年份、作品数、资金、旗标……）
  fx: [ {t:'fans', v:150} ],  // 读完后的效果
  say: ['……'],             // 结算后秘书补充的台词
  ask: {                   // 读完后让玩家选择
    q: '秘书的提问', title: '选择框标题',
    opts: [ {label, sub, fx:[...], say:[...]} ],
  },
}
```

### 效果类型（`MAG_FX`，可扩展）

| t | 参数 | 作用 |
|---|---|---|
| money | v | 资金增减 |
| fans | v | 粉丝增减 |
| trend | k, mul, months | k（类型 id / 内容 id / `all`）的作品销量 ×mul，持续 months 个月；企划书选择列表会标「流行中」 |
| flag | k, v | 记一个旗标，给后续事件的 `when` 用（`S.mag.flags.k`） |
| chain | id, after | after 个月后的杂志里强制刊出事件 id（不看 when/chance），用来做连续剧情 |

需要新效果（员工加能力、解锁类型、渠道分成变化……）时，在 `MAG_FX` 加一个函数即可，返回值是秘书要说的那句话。

### 推送稿

```js
magPush({cat:'news', title:'新作速报', text:[...]}, after=0)
```

只是一篇文章，没有效果。现在发售作品时会推一篇速报。

## 5. 现有示例事件（数值都是占位）

| id | 栏目 | 条件 | 效果 |
|---|---|---|---|
| intro | 动向 | 第一期（1 年 5 月） | 无 |
| summer | 动向 | 每年 7 月 | 动作 ×1.25，2 个月 |
| yearend | 动向 | 每年 12 月 | 全部 ×1.15，1 个月 |
| newyear | 动向 | 每年 2 月 | 桌游、解谜 ×1.2，1 个月 |
| rpg_boom | 动向 | 8 月以后，20%，冷却 12 个月 | RPG ×1.3，3 个月 |
| reader_first | 读者来信 | 发售过作品 | 粉丝 +150 |
| award | 特别报道 | 有作品总分 ≥ 32 | 资金 +3,000，粉丝 +800 |
| ad_offer | 杂志社来信 | 有作品且资金 ≥ 4,000，35%，冷却 6 个月 | 选择：花 2,000 金换粉丝 +500 / 放弃 |
