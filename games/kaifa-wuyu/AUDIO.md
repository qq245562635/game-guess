# 开发物语 · 音乐与音效

现在的音乐和音效全部由 `src/audio.js` 用 WebAudio 现场合成，不占任何资源文件，手机网页和微信小游戏都能直接用。
以后如果要换成正式录制 / 外包的音频，照下面的 key 交付文件即可，**缺哪个就继续用合成版**，可以一个一个替换。

## 怎么替换

1. 文件放进 `assets/audio/`，文件名 = key，格式 `mp3`（首选）/ `ogg` / `wav`，例如 `assets/audio/sfx_coin.mp3`。
2. 在 `assets/audio/index.json` 里写上 key 数组，例如 `["bgm_office","sfx_coin"]`。
3. 刷新页面即可。BGM 文件会无缝循环播放，请交付首尾能接上的循环段。

## 通用规格

- 采样率 44.1k / 48k，单声道或立体声都行；音效尽量短、开头不要留空白。
- 响度：BGM 约 -18 LUFS，音效峰值不超过 -3 dBFS。程序端已有总线压缩，别再做重压缩。
- 风格：和画面一样不走像素风，不要 8-bit 芯片音。轻快、干净、办公室日常感；参考原作的欢快感，但用真实乐器音色（电钢、颤音琴、贝斯、轻鼓、铜管）。

## 音乐

| key | 什么时候播 | 现在的合成版 |
|---|---|---|
| bgm_office | 平时（没有在开发的作品） | F 大调轻 bossa，94 BPM，电钢 + 颤音琴旋律 + 贝斯 + 边击 / 沙锤，8 小节循环，每三遍有一遍只留伴奏 |
| bgm_dev | 有作品在开发中 | C 大调明快 pop，118 BPM，四拍底鼓 + 拍手 + 反拍电钢 + 八分贝斯 |

两首切换时自动淡入淡出（约 0.8 秒）。播大段音效（完成、评分、升级）时音乐会自动压低一会儿。

## 玩家设置

「菜单 → 系统 → 声音」可以分别开关音乐和音效，设置记在本地（`localStorage` 的 `kaifa_wuyu_audio`）。
浏览器要求先有一次点击才能出声，所以第一次点屏幕之后才开始播放。切到后台会自动暂停。
