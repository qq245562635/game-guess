# 开发物语 · 场景一（办公室）美术需求 — 给 Codex

## 通用规则
- 视角：等角（isometric），地块 2:1 菱形，1 格 = 128 × 64 世界像素。
- 光源：左上方。物体可见面为「左前面」和「右前面」+ 顶面。
- 交付：透明 PNG，**按表中尺寸的 2 倍出图**（例如 128×176 → 256×352）。游戏会按表中尺寸缩放，比例不对会被拉伸。
- 锚点：表中「锚点」是图内坐标（1x 尺寸下），这个点会落在地块中心的地面上。物体底部中心请对准它。
- 文件名 = key，例如 `desk.png`、`char_0_a.png`。
- 预览方法：把图片交给程序接入（导入功能在精简版中已去掉）。
- 正式接入：把图片放进 `assets/` 并附 `assets/index.json`（内容是 key 数组，如 `["desk","chair"]`），页面启动时自动加载。
- 风格：非像素风（具体风格由你定），保持全套统一。
