# 开发物语 · 场景一（初始办公室）出图需求 — 给 Codex

风格以 Codex 第一版效果图为准：毛毡 / 纸感手作风，暖色，非像素。
这一版效果图整体方向通过，下面是**拆成游戏素材**的规格，以及效果图需要调整的地方。
UI 部分见 `UI需求.md`。

## 场景构成（和原作一致）

- 老板一张桌（老板坐着，面朝镜头）
- 秘书一张前台（秘书坐着，面朝镜头，靠近门口）
- 员工 4 人岛式工位：2×2 拼桌，后排 2 人面朝镜头，前排 2 人背对镜头
- 装饰：白板、书架 ×2、饮水机、盆栽 ×2、地毯、门口脚垫
- 以后办公室扩建时再加座位，这一版**只画 4 个工位**

程序里的占位图已经按这个布局摆好了，截图见 `docs/ui/01-主界面.png`，Codex 可以对照它的位置来画。

## 对效果图的调整意见

1. **严格按 2:1 等角网格画**：1 格 = 128×64 的菱形。效果图的墙和桌子比 2:1 陡，拆开后会和地板对不上。
2. **桌面上方留出空间**：员工头顶会冒「趣味 +3」之类的气泡，要能看清。
3. **房间不要堆满**：书架、绿植往墙边收，中间走道留出来。
4. **加上老板桌和秘书前台**：效果图里没有这两个。
5. **人物分正面和背面两套**：后排员工、老板、秘书用正面，前排员工用背面。

## 通用规则

- 交付透明 PNG，**按表中尺寸的 2 倍出图**。
- 「锚点」是图内坐标（1x 尺寸下），这个点落在所在地块中心的地面上。物体底部中心对准它。
- 文件名 = key。
- 接入方式：放进 `games/kaifa-wuyu/assets/`，并把 key 列表写进 `assets/index.json`（例如 `["desk","chair"]`），游戏启动时自动替换占位图。
