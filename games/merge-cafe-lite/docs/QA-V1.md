# Merge Café Lite V1 · QA 测试单（给 Muse）

V1 加了 6 块内容：店铺等级、连击 / 出售 / 防卡死、熟客 / 菜谱、棋盘障碍 / 套餐单 / 百搭星、每天回来、F 批美术。这份测试单按「玩家会遇到的顺序」排。程序自测已过（单元测试 89 条、端到端 149 条），这里请重点看**手感、节奏、真机表现**——自动化测不出来的东西。

## 怎么玩

- 地址：https://qq245562635.github.io/game-guess/games/merge-cafe-lite/ （合并到 main 后自动更新）
- 清档重来：地址后加 `?reset=1`
- 调试面板：地址后加 `?debug=1`，右上角会出现一排按钮（文案不进本地化，正式包不出现）：

| 按钮 | 作用 |
|---|---|
| `+1m` `+10m` `+1h` | 时间往后拨（体力、生成器冷却、订单倒计时跟着走） |
| `+1 day` | 拨到明天：测签到、每日任务换新 |
| `away 3h` | 模拟离开 3 小时：直接弹「欢迎回来」卡 |
| `daily done` | 今天的 3 条每日任务直接做完 |

| `+20 hearts` | 已解锁熟客各加 20 好感点 |
| `wild star` `chest` `bubble` | 放一颗百搭星 / 开一个宝箱 / 冒一个泡泡 |
| `energy 0` `pot full` `+100 coins` `+1000 coins` `+5 stars` | 改资源 |
| `fill board` `serve-ready` | 塞满棋盘 / 把订单要的东西都放上棋盘 |
| `skip tutorial` `reset` | 跳过引导 / 清档 |

建议：第一遍**不开调试面板**，当真玩家玩 2 × 15 分钟，记下感受；第二遍再用面板逐项过下面的清单。

## 一、真玩家视角（最重要，请写主观感受）

1. 前 10 分钟：引导是否清楚？第一次升级、第一次装修来得够不够快？
2. 第 1 天 30 分钟：有没有「没事干」或「被卡住」的时刻？有没有「一直有奖励」的感觉？
3. 弹窗会不会太多、太吵？（升级、升心、新菜谱、宝箱、签到、欢迎回来）
4. 第二天回来：签到 → 每日任务 → 离线收入，这套「回来有东西拿」的感觉是否成立？
5. 广告点位（5 个：体力、生成器回满、订单翻倍、泡泡、离线翻倍）是否自然、有没有逼人看？

## 二、功能清单

每条后面的数字是配置值，对不上请报。

### 店铺等级（M1）
- [ ] 左上角等级徽章；点开看经验条和「下一个开放的功能」
- [ ] 升级：全屏庆典 + 20 体力 + 等级×10 金币；每 5 级多一个宝箱（30 体力 / 100 金币 / 1 星）
- [ ] 一次升多级只弹一次庆典；拖拽中不弹，交单动画飞完再弹
- [ ] 功能按等级开放：2 每日任务 + 签到｜3 熟客 Mia｜4 套餐单｜5 菜谱 + Kai｜6 障碍｜7 百搭星 + Rose｜9 Leo + 离线 6 小时｜11 Marcus｜13 Chloe｜15 离线 8 小时

### 连击、出售、防卡死（M2）
- [ ] 2.5 秒内连续合成，从 x3 起出连击字；每 5 连 +5 金币、每 10 连 +1 体力；超过 2.5 秒重新数，不罚
- [ ] 平时点选物品，**不**出现「Sell」按钮（防误点）
- [ ] 满格又没得合时才出现「Sell +N」，4 秒后自动收起；点了一律先弹确认
- [ ] 卖 8 件回收桶满，送 5 体力
- [ ] 满格又没得合：自动选中最低级的物品并提示卖掉
- [ ] 一段时间不操作，一对能合的物品会轻晃
- [ ] 右上角喇叭：静音 / 取消，刷新后保留；所有音效都是合成音，听着是否刺耳

### 熟客、菜谱（M3）
- [ ] 熟客坐在修好的桌椅上，头顶显示心数（F 批心形图）
- [ ] 熟客订单卡头像角有心；升心弹大头像 + 心 + 台词；5 心开宝箱
- [ ] 2 心后每位熟客每天出 1 张熟客单（红框）
- [ ] 第一次做出某级物品弹「New Recipe」+ 金币；集齐一条链开宝箱
- [ ] Book 页：菜谱 / 熟客两个标签，进度条和台词显示正确

### 障碍、套餐单、百搭星（M4）
- [ ] 6 级起锁格变成沙堆 / 木箱，能看到埋的物品；拖同款物品上去挖开（白得一格 + 物品升 1 级）
- [ ] 付金币开格时弹窗写明里面是什么
- [ ] 4 级起出现套餐单（左上角角标）；3 分钟内交齐有 Perfect +50% 金币，顶边金色进度条
- [ ] 7 级起合成 6 级以上物品偶尔掉百搭星；拖到任意物品上升 1 级；不能卖

### 每天回来（M5）
- [ ] 2 级起每天第一次进游戏弹签到卡：7 格日历，今天那格高亮；断签不清零；第 7 天 3 星 + 宝箱
- [ ] Tasks 页顶部 3 条每日任务，数量随等级涨；做完一条有提示，3 条做完宝箱按钮亮、底栏 Tasks 有红点
- [ ] 每日宝箱：30 体力 + 100 金币 + 1 星，偶尔多一颗百搭星
- [ ] 离开 30 分钟以上回来弹「欢迎回来」卡（插画 + 金币），可看广告翻倍；上限 4 / 6 / 8 小时，封顶时卡上有提示
- [ ] 回来时弹窗顺序：欢迎回来 → 签到 → 其他

### V1.1 玩家吐槽对照（2026-10-22 起逐个合入）
- [ ] ① 备用咖啡壶：体力满了以后离开一会儿，回来顶栏体力旁出现杯子 + 点数（最多 40）；体力用光再点生成器，整壶自动倒进来、提示 "Coffee pot poured in"；壶也空了才弹体力见底，弹窗里有一句咖啡壶说明。调试面板 `pot full` 直接装满壶。请重点看：晚上那局（体力 100 开局）是不是能玩到 10 分钟左右才见底
- [ ] ② 高级单：要 6 级以上物品的单（金框）卡片右下角没有倒计时，换成 ⚡+5 / +10 / +20；放着不管不会被换掉；点开写明不限时 + 返体力；交齐体力跳一下、提示 "Big order tip"
- [ ] ③ 储物架 + 回收桶：棋盘下面一条（横屏在左下）。4 级前储物架写 "Pantry opens at Lv 4"、拖上去回弹；4 级后拖进去 / 拖回棋盘 / 架上直接拖给订单 / 架位互换都正常；点 "1k" 那格花金币扩建。任何时候拖进回收桶就卖、不弹确认，桶上方 Undo 倒数 10 秒，点了东西回原位、金币退回。请重点看：手机竖屏上这一条格子够不够大、会不会拖错格

## 三、设备

请至少过：iPhone Safari 竖屏、Android Chrome 竖屏、电脑 Chrome 横屏（1280×720）、iPad。重点看：
- 弹窗在小屏上有没有被裁（签到日历 7 格、欢迎回来插画）
- Tasks 页内容多了以后能不能滚动
- 帧率：手机上开 `?debug=1` 看右上角 fps，合成拖拽时应 ≥ 50
