# 彩路小镇

参考 Mini Motorways 玩法规则的原创复刻原型。名称、配色、图形全部原创，没有使用原游戏任何素材。

## 运行

浏览器直接打开 `index.html`。竖屏是 14×20 网格，横屏是 22×14。

## 玩法

- 按住拖动铺路，把同色小屋连到同色大楼的入口。每格消耗 1 个路块；右键或橡皮擦除，路块返还。
- 大楼按时间冒出订单点，同色小车送达一单得 1 分。每个小屋有 2 辆车。
- 方楼订单超过 7、圆楼超过 10 开始红色倒计时（25 秒）。每送达一单倒退 3 秒，订单回落后计时慢慢消退，走完游戏结束。
- 每周结束二选一领补给，都附带路块：
  - 桥：从岸边把路拖进河里自动使用，一段河只耗 1 座
  - 环岛：点在路口上，过路口几乎不减速
  - 红绿灯：点在路口上，横竖交替放行
  - 高速路：依次点两个路点直连，无视河流，自动编号
- 每两周解锁一个新颜色，第 3 周起出现圆楼，订单速度随时间加快。昼夜交替只是配色变化。

快捷键：空格暂停，`1` / `2` 切速度，`E` 橡皮，`Esc` 回到画路。

## 实现要点

- 路网是图：节点是道路格、小屋、大楼入口，边由拖动生成；高速路是额外的长边。
- 派车用 Dijkstra：从大楼入口出发找最近的空闲同色车，倒计时中的大楼优先。小屋和入口只能当起点或终点，不能穿行。
- 路口（度数 ≥3）有通行惩罚，寻路和车速都会受影响；同车道跟车排队。
- 删路后所有在途车辆重新寻路，无路可走的车 10 秒后瞬移回家。
- 刷小区和处理厂前会先试放，按可修路格划分连通区域：新小区必须能通到同色处理厂，原本能通的小区不能被切断；找不到合适位置就这次不刷。保证不会出现永远连不上的小区。

## 调参

数值集中在 `src/game.js` 顶部的 `CFG`：周长、倒计时、订单速率、刷屋和刷楼间隔、车速、初始路块等。
