# 樱花镇

动森风格 3D 小镇的 WebGL 渲染样片，用来验证 Three.js 能不能做出参考图那种柔和、通透的画面。目标平台是 Steam 桌面版。

## 运行

浏览器直接打开 `index.html`。three.js r155 从 jsDelivr 加载，需要联网。

## 操作

- WASD / 方向键移动，Shift 奔跑
- 点击地面寻路
- Q / E 或右键拖拽旋转视角，滚轮缩放
- 河边按 F 钓鱼，H 隐藏界面

## 画面里有什么

- 程序生成的房屋（瓦片屋顶贴图用 canvas 画）、树、灌木、草、蕨、花、栅栏、长椅、路灯、木桥
- 草、树冠、花在顶点着色器里做风动，草会被角色踩开
- 卡通河流：滚动噪声做水纹，按河岸深度算泡沫，噪声阈值做波光
- 树挡住角色时，树冠用抖动镂空露出角色
- 后处理：景深（前景树冠虚化 + 远景模糊）、两级 Bloom 柔光、分离色调调色、暗角、指数色调映射
- 时间滑块控制太阳角度、天光、雾色、窗户和路灯亮度

左上角面板可以分别开关各项效果、切换画质，并显示 FPS、draw call 和三角面数。

## 目录

```
index.html          构建产物，单文件可玩版本
src/game.js         场景、着色器、后处理、输入
src/game.src.html   页面模板与样式，构建时内联 src/game.js
tools/build.py      生成 index.html：python3 tools/build.py
```
