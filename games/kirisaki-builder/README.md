# 雾岬港町

在「雾岬渔港」沙盘基础上做的渔港建造经营游戏，单文件 `index.html`，直接打开即可运行。

## 玩法

- 底部工具栏选建筑，点击地块放置；绿色可建，黄色能建但不会运转（比如没挨着道路），红色不能建。
- **陆地**：道路、民居（住 4 人）、伐木场（周围树越多产量越高）、鲜鱼市场（卖掉库存 15 条以上的鱼）、仓库（储量 +100）、樱花公园（提升满意度）。
- **海面**：码头（第一排要建在岸边道路正下方，之后接着往外延伸）、渔船（停在空码头上，每趟出海 8 小时带回约 6 条鱼）、大型渔船（3 名工人，每趟约 15 条）、养殖网箱（稳定小量产鱼）。
- **拆除**：返还一半花费；砍树得 4 木材。码头上有船时先拆船。
- **资源循环**：居民缴税并提供工人，每小时吃鱼；缺鱼满意度暴跌、人口流失。满意度影响税收和人口增长。
- **每天**随机天气（晴 / 太阳雨 / 雨，影响渔获）和鱼价（3–6），昼夜自动流转，夜里窗户和灯塔会亮。
- 六个阶段目标，完成有奖励；最终目标是人口 40、金币 2000。
- 速度：暂停 / 1× / 2× / 4×。自动存档到浏览器本地，菜单里可以重新开始。

## 操作

- 左键拖动旋转，右键拖动平移，滚轮缩放；手机上单指旋转、双指缩放平移，轻点放置。
- 快捷键：1–9 选工具，0 拆除，Esc 取消，空格暂停。

## 技术

- Three.js r128（cdnjs）+ OrbitControls / GLTFLoader（jsDelivr）。
- 大型渔船用外部模型 `models/margo-07.glb`，加载后按材质合并成 17 块网格（原模型 221 个零件）以减少绘制次数；直接用 file:// 打开或加载失败时，退回代码生成的放大版渔船。
- 民居（两种）、伐木场、鲜鱼市场、仓库、樱花公园、码头、养殖网箱、小渔船和灯塔用 `models/harbor-pack/` 里的低多边形 glb（Codex 制作，规格见该目录的 `交付清单.md`）。材质名 `Window` / `Lamp` 会换成游戏里夜间发光的材质，`Sign` 面板贴上招牌文字，小渔船的 `HarborBlue` 按船只换色。
- 画面是卡通渲染：所有材质用三段色阶的卡通材质（亮面、半影、暗面），再用一次法线和深度的后期处理画出描边，远处的描边会淡出。不支持 WebGL2 的浏览器只保留色阶，不画描边。
- 模型加载失败或用 file:// 直接打开时，自动退回代码生成的模型，游戏照常能玩。
- 场景风格和部件（土层剖面、半透明海水、灯塔、天气、昼夜）沿用 `games/kirisaki-harbor`。
