# 立体八卦

周易主题的 WebGL 交互样片，单文件 `index.html`，直接打开即可运行。

## 内容

- **生成次第**：底部五个阶段，按邵雍「加一倍法」逐爻生长：太极 → 两仪 → 四象 → 八卦 → 六十四卦。
- **卦位**：先天（伏羲）/ 后天（文王）切换，八卦沿最短弧换位；方位按古图上南下北、左东右西。
- **八经卦**：点击查看《象传》、性情、家人、五行、人身、动物、先天数、洛书数。
- **六十四卦外环**：伏羲圆图排法（乾起于南，坤终于北）。点击后六爻飞到中央成立体卦，面板给出文王序、先天序、上下卦，错卦、综卦、互卦可点击跳转。
- **起卦**：三钱法，背面计 3、字面计 2；铜钱抛掷动画，六爻成卦后标出本卦、变卦和动爻，可翻转查看变卦。随机数用 `crypto.getRandomValues`。

## 技术

- Three.js r128（cdnjs），后期用 r128 examples 里的 EffectComposer + UnrealBloomPass（jsDelivr）；后期脚本加载失败时自动退回普通渲染。
- 水墨背景为全屏 fbm 着色器，气流为螺旋粒子着色器，六十四卦外环为 InstancedMesh。
