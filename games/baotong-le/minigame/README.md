# 爆桶了 · 微信小游戏工程

由 `../tools/build.py` 生成，**不要直接改 `game.js`**，改 `../src/` 里的源码后重新构建。

## 打开

1. 微信开发者工具 → 小游戏 → 导入项目，目录选这个 `minigame/`。
2. AppID 选「测试号」（`project.config.json` 里默认是 `touristappid`）。以后换正式 AppID，只改 `project.config.json` 的 `appid`，重新构建不会覆盖。
3. 编译后模拟器里能玩；点「预览」用手机微信扫码上真机。

## 真机检查清单

- [ ] 主菜单 → 选关 → 关卡介绍 → 开始；通关结算的星星动画；退出再进来星星还在

## 字体

默认用手机系统字体（标题用粗体代替快乐体）。想用和网页版一样的字体：按 `../tools/subset_font.py` 里的说明生成 `display.ttf` / `num.ttf`，放进 `../fonts/` 后重新构建，会自动打包进 `minigame/fonts/` 并用 `wx.loadFont` 加载。
