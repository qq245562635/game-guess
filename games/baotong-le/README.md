# 爆桶了·垃圾分类大作战

[彩路小镇](../cailu-xiaozhen/)（Mini Motorways 玩法复刻）的换皮版本。核心规则一行没动，只换主题、美术、文案和音效，外加一个微创新：督导员突击检查。所有图形用 Canvas 原创绘制，音效用 WebAudio 合成，没有任何外部素材。

## 运行

浏览器直接打开 `index.html`。横屏 22×14，竖屏 14×20。

## 元素映射

| 原版（彩路小镇） | 爆桶了 |
|---|---|
| 小屋 | 小区投放点：米色楼群 + 门口分类桶，底色标明所属分类 |
| 大楼 | 分类处理厂：蓝=可回收分拣中心、红=有害垃圾处理厂、绿=湿垃圾生化厂、灰=干垃圾焚烧厂（带烟囱） |
| 五种颜色 | 国标四分类色，解锁顺序 蓝 → 绿 → 灰 → 红 |
| 订单点 | 待清运垃圾袋，漂浮在厂房上方，每行 5 个 |
| 小车 | 清运车：小卡车，车顶橙色警示灯，夜间开大灯 |
| 道路 / 路块 | 清运路线 / 路段额度 |
| 桥 / 高速路 | 跨河大桥 / 转运高架（亮橙 #F5A623，编号） |
| 周补给 | 每周市政拨款二选一 |
| 分数 | 清运量（袋） |
| 订单爆满倒计时 | 投诉倒计时：红色脉冲圈 + 感叹号，走完即“投诉爆表” |

配色：日间米白 `#F5F1E8`，夜间深蓝 `#1B2A4A`，道路深灰 `#4A4A4A`。

## 督导员突击检查（新增）

- 第一次在第 2 周左右触发，之后每 2–3 周一次（`CFG.inspFirst` / `CFG.inspEvery`）。
- 随机挑一座已经有同色小区连通、且没在投诉倒计时中的处理厂，90 秒内要清运 N 袋。N 从 6 起，每次 +2，封顶 14。
- 检查期间该厂冒垃圾袋速度 ×2（不然袋子不够拉），派车时优先照顾它。
- 成功：+15 路段 + 1 个随机设施；失败：该厂直接 +3 袋。
- 显示：顶部深蓝横幅（厂名、进度、剩余秒数，最后 20 秒变红），地图上目标厂外圈橙色虚线 + 剩余时间弧 + “督”字角标，复用投诉倒计时的画法。

无头模拟里（自动连路、不做任何优化）40 局检查通过 30 局，难度大致合适，后续按实测再调。

## 音效

垃圾袋冒出“噗”、送达压缩机“哐当”、每 10 袋和拨款时“叮”、投诉倒计时“嘀嘀”（越接近爆表越急）、检查通过“叮叮”。左上角喇叭按钮或 `M` 键静音，设置会记住。

## 快捷键

空格暂停，`1` / `2` 切速度，`E` 拆路，`M` 静音，`Esc` 回到修路。

## 刷新规则

- 刷小区和处理厂前会先试放，按可修路格划分连通区域：新小区必须能通到同色处理厂，原本能通的小区不能被切断；找不到合适位置就这次不刷。保证不会出现永远连不上的小区。

## 调参

数值都在 `src/game.js` 顶部的 `CFG`，与彩路小镇保持一致，检查相关的是 `insp*` 开头的几项。
