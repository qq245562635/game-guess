# 爆桶了·垃圾分类大作战

[彩路小镇](../cailu-xiaozhen/)（Mini Motorways 玩法复刻）的换皮版本。规则沿用彩路小镇，换了主题、美术、文案和音效，加了一个微创新：督导员突击检查。v2 根据试玩反馈放慢了节奏、重做了铺路手感，v3 改了刷点规则、加了接通反馈（见下文）。所有图形用 Canvas 原创绘制，音效用 WebAudio 合成，没有任何外部素材。

## 运行

- **网页**：浏览器直接打开 `index.html`（GitHub Pages 上就是这个文件）。横屏 22×14，竖屏 14×20。
- **微信小游戏**：微信开发者工具 → 导入项目 → 选 `minigame/`，AppID 选测试号。详见 [minigame/README.md](minigame/README.md)（含真机检查清单）。

两边是同一套代码，v4 起渲染全部改成纯 WebGL（不依赖引擎），界面也画在画布里。

## 督导员突击检查（新增）

- 第一次在第 3 周左右触发（150–200 秒），之后每 2–3 周一次（`CFG.inspFirst` / `CFG.inspEvery`）。
- 随机挑一座已经有同色小区连通、且没在投诉倒计时中的处理厂，90 秒内要清运 N 袋。N 从 5 起，每次 +1，封顶 10。
- 检查期间该厂冒垃圾袋速度 ×1.6（不然袋子不够拉），派车时优先照顾它。
- 成功：+15 路段 + 1 个随机设施；失败：该厂直接 +3 袋。
- 显示：顶部深蓝横幅（厂名、进度、剩余秒数，最后 20 秒变红），地图上目标厂外圈橙色虚线 + 剩余时间弧 + “督”字角标，复用投诉倒计时的画法。

v1 是第 2 周就来、要 6–14 袋，自动连路的模拟里 40 局通过 30 局；v2 放宽后自动连路基本都能过，真人主要看同色小区接得够不够。

## 音效

垃圾袋冒出“噗”、送达压缩机“哐当”、每 10 袋和拨款时“叮”、投诉倒计时“嘀嘀”（越接近爆表越急）、检查通过“叮叮”。左上角喇叭按钮或 `M` 键静音，设置会记住。

## 快捷键

空格暂停，`1` / `2` 切速度，`E` 拆路，`Z` 撤销上一笔，`M` 静音，`Esc` 回到修路。暂停时也能铺路。

## v3 刷点与接通反馈（试玩反馈：路点太随机、连起来没有爽感）

**刷点**（`houseScore` / `spawnHouse`）：
- 同色小区 3–5 户成团（`CLUSTER_MAX`），新小区优先紧挨着没满的同色团；团满了就在本色处理厂附近另起一团。
- 分区：离本色处理厂越近越好，贴着别色小区、或明显更靠近别色处理厂的位置扣分；新处理厂选址避开别色小区密集处。
- 贴着已有道路的空地加分，修好的路会"长出"新住户。至少留两面能修路，不会把自己堵死。

`node tools/spawn_stats.js 60 4` 统计第 4 分钟的分布（60 局，约 28 户）：

| | v2 | v3 |
|---|---|---|
| 紧挨着有同色小区 | 47% | 97% |
| 2.5 格内没有同色 | 30% | 2% |
| 紧挨着有别色小区 | 32% | 0% |
| 平均一团 | — | 4 户 |

**接通反馈**（`checkConnections`）：
- 小区第一次接通到同色处理厂：从小区沿路线扫一道本色光冲到厂门口，"叮咚"一声，弹出"接通！"。一次接通多户时每户亮一圈色环，文字只显示连击。
- 处理厂第一次有小区接入：厂房弹一下，"开工！"。
- 一笔接通 ≥2 户显示"一笔接通 ×N"，≥3 户奖励 N 个路段。奖励只算每户第一次接通，撤销重连刷不了。
- 每接通一户就马上开出一辆车（不用等垃圾袋，补的袋数不超过上限，不会触发投诉）。
- 清运车去程车斗上驮着垃圾袋；送达飘 "+1"，厂房一缩一弹，右上角清运量跳一下。
- 车流染色：车刚跑过的路段留一道本色，约 2 秒褪掉，繁忙干道看起来是彩色流动的。

## v4 纯 WebGL + 微信小游戏

为了上微信小游戏（没有 DOM，只有一块画布），渲染和界面整个重写成 WebGL，规则层一行没动。

- **规则层** `src/core.js`：地图、刷新、路网、派车、督导员、周拨款、接通判定。不碰 DOM、不画图，模拟脚本只加载这一个文件。
- **渲染器** `src/gl.js`：WebGL1，一个 SDF 着色器画圆角矩形、胶囊线段、圆弧（可虚线）和贴图，全部合批，通常一帧一次 draw call。文字按字缓存进 2048² 图集，垃圾袋、厂房图标、工具栏图标用离屏 2D 画布画一次后进图集。
- **画面** `src/view.js`：逐项对应原 Canvas 版（网格、河、道路、高架、小区、处理厂、车、扫光、飘字）。
- **界面** `src/ui.js`：顶部栏、督导员横幅、工具栏、提示条、三张卡片，全部画在画布里，自己做点击判定。微信里顶部栏放在右上角胶囊按钮下方。
- **输入** `src/input.js`：v2 的铺路手感原样保留。
- **平台层** `src/platform.web.js` / `src/platform.wx.js`：画布、触摸、存档、音效（WebAudio / `wx.createWebAudioContext`）、震动、字体、分享。
- **构建** `tools/build.py`：同时产出 `index.html` 和 `minigame/`；会检查小游戏包里没有 `document`/`window` 等浏览器对象，也没有老 JS 引擎不认的 `?.` `??` `{...}`。

包体：小游戏约 80 KB（系统字体），加上快乐体子集约 300 KB 左右，主包上限 4 MB。
验证：浏览器里跑通开始 → 铺路 → 一笔接通 → 撤销 → 周拨款 → 投诉爆表 → 重新上岗；另外用模拟的 `wx` 环境（把 `document`、`window`、`navigator`、`localStorage`、`performance` 全部置空）跑 `minigame/game.js`，启动、点按钮、拖路、震动、音效都正常。后期满屏每帧 JS 渲染约 1 ms。真机还没测。

## v5 关卡模式

主菜单分「关卡模式」和「无尽模式」。关卡共 15 关，通关一关解锁下一关，每关三颗星：完成目标 / 全程没触发投诉倒计时 / 在规定周数内完成。进度存在本地（网页 localStorage，小游戏 wx.setStorageSync）。

设计思路：
- 前 4 关一关只教一件事（修路 → 颜色配对 → 一笔接通 → 过河），第 1 关画出会动的示范路线，接通后消失。
- 第 5 关起城区按周往外扩，城区外盖一层雾、隐约能看到未来的河和地块；镜头跟着城区平滑拉远，所以开局格子大、越往后看到的地图越大（7×9 → 15×22）。
- 新元素逐个解锁：颜色 → 河与桥 → 扩城 → 第三种颜色 → 环岛 → 圆形大厂 → 督导员 → 红绿灯 → 第四种颜色 → 两条河与高架 → 节奏加快。工具栏只摆本关用得上的设施，新解锁的那个开局闪框提示。
- 关卡用固定种子，同一关每次开局地图一样，之后的刷新随玩家节奏自然分岔。
- 早期关卡没有设施可选时，每周直接发 20 路段，不弹拨款卡片。

## 刷新规则

- 刷小区和处理厂前会先试放，按可修路格划分连通区域：新小区必须能通到同色处理厂，原本能通的小区不能被切断；找不到合适位置就这次不刷。保证不会出现永远连不上的小区。

## v2 节奏（试玩反馈：太难、太快）

数值都在 `src/core.js` 顶部的 `CFG`，注释里留着 v1 的原值。

| | v1 | v2 |
|---|---|---|
| 一周时长 | 60 秒 | 70 秒 |
| 新小区间隔 | 8.5 秒 | 13 秒 |
| 第一座新厂 / 之后间隔 | 40 秒 / 72 秒 | 60 秒 / 100 秒 |
| 新厂第一袋 | 5–9 秒 | 15–20 秒 |
| 冒袋基础间隔 / 加速尺度 | 11 秒 / 280 | 14 秒 / 420 |
| 投诉倒计时 / 回落速度 | 25 秒 / ×0.6 | 40 秒 / ×1 |
| 清运车速度 | 2.4 | 2.7 |
| 开局路段 / 大桥 | 36 / 1 | 44 / 2 |

折算下来：前几分钟每分钟要铺的路从约 10 次降到约 7 次；一座新厂冒出来不管它，到投诉爆表的时间从 60–95 秒放宽到 100–145 秒。新厂自带的小区优先刷在同一岸，不用桥也能先连上。

`tools/bot.js` 是难度基准机器人（会接小区、也会给新厂找小区，可设反应间隔和手滑概率）。它规划得近乎完美，能一直玩下去，测不出真人的压力，只用来确认改数值没有把游戏改坏。真人难度以试玩为准。

## v2 铺路手感（试玩反馈：手感面、容易点错）

- 按下时吸附到 0.85 格内最近的小区、入口或道路；按在处理厂身上就从它的入口开始铺。环岛、红绿灯、高架同样吸附。
- 在空地上轻点不扣路段，拖出一格才开始铺。
- 防抖：手指要越过格子边界 0.2 格才进入下一格，沿直线拖时手抖不会拐出小岔路（岔路口会让清运车减速近六成，误触以前会直接拖垮效率）。
- 「撤销」按钮 / `Z`：撤掉上一笔，路段、大桥原数返还，最多记 30 笔。
- 每铺一格有轻微的“嗒”声、手机震动（安卓）和白色闪光；拖动时方框跟着路头走。

浏览器里模拟同一笔带上下抖动的横拖：v1 画出 10 格、4 格歪到别的行、多出 1 个路口、还没连上小区，轻点一下扣 1 格；v2 是笔直 6 格、连上小区，轻点不扣。
