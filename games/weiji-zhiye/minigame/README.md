# 未寄之夜 · 微信小游戏工程

由 `../tools/build.py` 生成，**不要直接改 `js/` 和 `game.js`**，改 `../src/` 里的源码后重新构建。`project.config.json` 已存在时不会被覆盖，换正式 AppID 只改它。

## 打开

1. 微信开发者工具 → 小游戏 → 导入项目，目录选这个 `minigame/`。
2. AppID 选「测试号」（默认 `touristappid`）。
3. 编译后模拟器里能玩；点「预览」用手机微信扫码上真机。

## 真机检查清单

- [ ] 标题、顶部返回按钮没有被胶囊按钮和刘海挡住，贴纸册不压 Home 条
- [ ] 雨声、揭纸、吸附、翻页、完成提示能听到（依赖 `wx.createWebAudioContext`，基础库 2.19+）；声音开关有效
- [ ] 按住拖出贴纸：偏移到指尖上方、接近目标时轮廓变暖色、松手吸附并轻震；放错弹回
- [ ] 双指缩放、单指平移后，小物件（水杯、收纳盘、梳子）仍能准确放下
- [ ] 第 8、16 张后贴纸册各翻页一次；24/24 后出现全景和「继续剧情」
- [ ] 耳饰近景、记忆画面在手机上看得清；A、B 两个选择都能走到章节卡
- [ ] 贴到一半、刚贴完、选完后分别杀进程重开，都回到正确位置
- [ ] 低端安卓机上贴纸拖动不掉帧
