# 恒星工坊 · 微信小游戏工程

由 `../tools/build.py` 生成，**不要直接改 `game.js`**，改 `../src/` 里的源码后重新构建。

## 打开

1. 微信开发者工具 → 小游戏 → 导入项目，目录选这个 `minigame/`。
2. AppID 选「测试号」（`project.config.json` 里默认是 `touristappid`）。以后换正式 AppID，只改 `project.config.json` 的 `appid`，重新构建不会覆盖。
3. 编译后模拟器里能玩；点「预览」用手机微信扫码上真机。

## 真机检查清单

- [ ] 开始页、顶部栏没有被右上角胶囊按钮和刘海挡住，底部快捷栏不压 Home 条
- [ ] 按钮、快捷栏一次就能点中（手指按住稍久也行）
- [ ] 点矿脉：机甲飞过去采矿，飘「+1 铁矿」
- [ ] 建造模式：点一下放蓝图、拖动连续放、长按旋转；无人机按序号施工
- [ ] 拉传送带：按住拖出 L 形，弯道自动生成；物品在带上流动顺滑
- [ ] 双指缩放、平移；拉远后传送带变成按物品着色的色条
- [ ] 产能面板点一行，地图上产出 / 消耗建筑亮绿 / 红框
- [ ] 切到后台再回来，进度还在；离开几分钟后回来有「离线」卡片（需要有东西在进储物箱）
- [ ] 音效和震动；右上角菜单能转发
- [ ] 性能：1 万个物品在带上时帧率（策划案目标：中低端安卓 30fps，单 tick < 8 ms）

## 抖音小游戏

平台层只用了画布、触摸、存储、WebAudio、震动、分享、`onHide` 这几类 API，抖音小游戏里都有同名的 `tt.*`。适配时复制一份 `src/platform.wx.js` 改成 `tt`，在 `tools/build.py` 里多出一个工程目录即可。
