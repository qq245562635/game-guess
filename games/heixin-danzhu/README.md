# 黑心弹珠摊（H5 原型）

夜市弹珠摊经营小游戏。顾客花 ¥2 打一颗弹珠，落进哪格赔哪格；玩家用机关暗中操控弹珠，在**人气**和**嫌疑**之间找平衡，每天收摊交摊位费。

## 运行

直接用浏览器打开 `index.html` 即可，无需构建工具或服务器。

## 目录

```
index.html          构建产物，单文件可玩版本
src/engine.js       弹珠物理引擎（纯逻辑，无 DOM，可在 node 下跑）
src/game.js         游戏层：经营循环、机关放置、HUD、渲染
src/game.src.html   页面模板与样式，构建时内联 engine.js 和 game.js
tools/build.py      生成 index.html：python3 tools/build.py
tools/sim.js        数值模拟：node tools/sim.js
```

改完 `src/` 下的文件后运行 `python3 tools/build.py` 重新生成 `index.html`。

## 当前规则

- 每颗弹珠 ¥2，奖格从左到右：谢谢惠顾 / 1元 / 谢谢惠顾 / 3元 / 8元 / 3元 / 谢谢惠顾 / 1元 / 谢谢惠顾
- 每天 70 秒；收摊交摊位费，第 1 天 ¥12，之后每天 +¥8，钱不够就破产
- 进度条 45%–62% 为城管巡逻段，期间嫌疑增长翻倍
- 机关：弹簧拳头 ¥10（每出一拳嫌疑 +3，点击换朝向）、磁铁 ¥14（吸住弹珠时嫌疑持续上涨），台面最多 5 个，跨天保留
- 拍桌子：把钉阵里的弹珠全部打乱，嫌疑 +14、人气 -2，冷却 5 秒
- 嫌疑系数 = (0.6 + 围观人数 × 0.12) × 巡逻倍率；围观人数 ≈ 人气 / 12；嫌疑每秒自然回落 2 点，满 100 被掀摊
- 人气：中 8 元 +6、中 3 元 +2、中 1 元 +1、谢谢惠顾 -1.5；人气越高顾客来得越快

## 模拟结果（tools/sim.js，每组 3000 颗）

| 台面配置 | 每颗平均赔付 |
|---|---|
| 不放机关 | ¥1.63 |
| 1 块磁铁（左侧谢谢惠顾上方） | ¥1.35 |
| 2 块磁铁（两侧谢谢惠顾上方） | ¥1.03 |
| 2 块磁铁 + 2 个拳头 | ¥0.82 |

自然落点接近均匀（每格约 10%–16%），并不是经典 Plinko 的中间高两边低，详见设计评审中的第 2 条。

## 技术说明

- Canvas 2D 渲染，固定步长 1/60 秒，每步 4 个子步
- 物理使用带种子的 xorshift 随机数，同一种子可完整复现一局，可用于回放和排行榜校验
- 震屏和闪白在 `prefers-reduced-motion` 下会减弱；手机震动使用 `navigator.vibrate`，iOS Safari 不支持，做微信小游戏时改用 `wx.vibrateShort`
