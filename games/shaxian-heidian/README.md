# 厨神附体：沙县黑店（原型 v0.1）

开罗式像素经营小游戏，纯 WebGL 2D，首发微信小游戏。当前是里程碑 1「原型」：验证系统定价博弈好不好玩。

## 目录

```
src/
  config.js          所有数值、菜谱、设施、客人、剧情文本（换皮只改这里）
  rng.js             可复现随机数
  sim.js             经营模拟（纯逻辑，不碰渲染，Node 可跑）
  platform/web.js    浏览器实现：存档、广告（模拟）、输入
  platform/wechat.js 微信实现：wx 存档、激励视频广告、触摸
  render/gl.js       WebGL 精灵批处理
  render/atlas.js    占位像素图集（程序绘制）
  render/ui.js       UI 层：离屏 2D 画布 → 纹理
  game.js            主循环、布局、输入、弹窗、剧情
  main.js            启动
tools/
  build.js           构建（无依赖，按顺序拼接）
  simulate.js        经济模拟：多种定价策略跑 N 天
index.html           浏览器试玩，双击打开（构建生成）
minigame/            微信小游戏工程，开发者工具直接导入（构建生成）
```

## 常用命令

```
node tools/build.js            # 生成 index.html 和 minigame/
node tools/simulate.js 40 20   # 跑 40 天 × 20 局，看各策略的现金/口碑/黑店值曲线
```

浏览器控制台里 `__shaxian.game.sim` 可以直接改状态调试（如 `__shaxian.game.sim.cash = 99999`）。
存档在 localStorage 的 `shaxian_save_v1`，清掉即重开。

## 微信小游戏

1. 微信开发者工具 →「导入项目」→ 选 `minigame/`。
2. `project.config.json` 里的 `appid` 现在是测试号，换成你的。
3. `src/config.js`：`AD_UNITS.rewarded` 换成真实激励视频广告位；上线前把 `DEBUG_FREE_ADS` 改为 `false`（否则广告失败也会发奖励）。

## 已实现（原型范围）

- 8×8 网格店面：后厨两行放灶台/蒸笼/汤锅，前厅放桌椅/装修，拆除退一半
- 4 道沙县基础菜，每道三档定价：原价 / 半价 / 系统价
- 黑店值、口碑双轴；店况四象限；黑店值越高画面越暗越紫
- 5 类客人：上班族、老街坊、网红、美食家、富豪（价格敏感度不同）
- 厨师招聘，做菜进度条，等太久会走人
- 每日系统任务、举报事件、超过 80 黑店值触发检查罚款
- 每 10 天交房租（2 万 → 2.5 万 → 4 万 → 5 万），交不上可看广告延期 3 天一次
- 广告点位：打烊营收 +50%、房租延期
- 剧情对话卡：开场、首次举报、首个富豪、首次检查、首月交租、破产

## 数值现状（tools/simulate.js，20 局平均）

| 策略 | 第 10 天现金 | 第 30 天结果 |
| --- | --- | --- |
| 一直系统价 | 约 2.8 万 | 口碑卡在 10 左右，第 3–4 个月交不起房租 |
| 看黑店值调价 + 投资 | 约 2.4 万 | 口碑冲到 80+，富豪变多，营收翻倍 |
| 一直原价 | 约 0.5 万 | 第 1 个月就交不上 |

## 换美术

`render/atlas.js` 里的 `SPR` 名字表就是图集规格：每个精灵 16×16，按顺序排在 256×64 的图里。
让 GPT 按这个名字表和尺寸出一张 PNG 图集，把 `build()` 改成加载图片即可，其他代码不动。
人物每种 2 帧（`_0` `_1`），用于走路动画。

## 换皮

剧名、角色名、剧情台词都在 `config.js` 的 `TEXT` 和 `STORY`。上线前替换为原创内容或授权内容。
