**`stove` 重画要点**

1. 台柜轮廓照 `art/_templates/guide_counter.png` 的蓝线画：沿左右方向**顶满整格**，左右两个侧面正好落在格子边上；台面高 18 像素。对照 `art/_templates/stove.png`（占位图已改成这个形状）。
2. 左前面画两扇柜门，竖缝和把手各 1 像素，别画细碎反光。
3. 台面上：炒锅占台面左半边，锅是一块深色椭圆、锅沿 1 像素亮边；火苗只用 2–3 个橙黄像素露在锅边，不要整团橙色。右后角一瓶酱油（红盖）。
4. 并排拼三张自查：把三张 `stove.png` 按占位图那样错开 24×12 像素摆在一起，台面应连成一条没有缝。

程序这边配套：角色只交了部分帧时，缺的帧用已交的帧顶上（`worker_1` `worker_b1` 没交前走路不再闪占位图）。
