四种玩法怎么选结论：悉尼进、墨尔本出

澳洲很大，7天只够玩东南角或者加一个点。上海浦东到悉尼、墨尔本、布里斯班都有直飞，所以先看 想要什么样的风景：城市 + 海岸、自驾看山、还是去热带潜水。珀斯和乌鲁鲁离得太远，这次不考虑。

推荐

悉尼进、墨尔本出 + 大洋路

★★★★★
悉尼 → 蓝山 → ✈ 墨尔本 → 大洋路 → 墨尔本 → 菲利普岛
  • 澳洲最有代表性的东西基本都有：歌剧院、海滩、蓝山、十二门徒石、野生考拉、小企鹅。
  • 只自驾3天，其余时间坐火车、轮渡、电车，不会太累。
  • 两头都是上海直飞，中间悉尼飞墨尔本只要1.5小时，不走回头路。
  • 要买开口程机票，加一张国内航班（约 A$120–180/人）。
  • 五月是深秋，水太凉，不适合下海游泳，海边以走路看风景为主。
第一次去澳洲最稳的走法，城市和自然各占一半。
喜欢自驾就选它

墨尔本 + 塔斯马尼亚自驾

★★★★
墨尔本 → ✈ 霍巴特 → 酒杯湾 → 摇篮山 → 朗塞斯顿 → ✈ 墨尔本
  • 五月初正好赶上塔斯马尼亚 落叶山毛榉变黄（Fagus），摇篮山最美的时候。
  • 人少、路好开，海鲜和生蚝便宜。
  • 风景和新西兰南岛很像，选了新西兰就没必要再来这个。
  • 上海没有直飞塔斯马尼亚，要在墨尔本转机；山区冷，摇篮山可能下雪。
如果你们本来就想自驾看山，但新西兰机票太贵，这个是平替。
想要暖和就选它

悉尼 + 凯恩斯大堡礁

★★★★
悉尼 → ✈ 凯恩斯 → 大堡礁出海 → 热带雨林 → ✈ 悉尼
  • 凯恩斯五月是旱季开始，20–29°C，能浮潜看珊瑚。
  • 一趟里有城市、有热带海岛，和另外两个方案区别最大。
  • 悉尼到凯恩斯要飞3小时，回程大概率要回悉尼或在香港转机，路上时间多。
  • 墨尔本和大洋路就去不了了；出海一天每人约 A$250–350。
四个人里有想潜水、怕冷的，选这个。
不太推荐

布里斯班 + 黄金海岸

★★★
布里斯班 → 黄金海岸 → 拜伦湾 → 布里斯班
  • 上海直飞布里斯班，往返同一个城市，票好买；天气比悉尼暖。
  • 主题公园多，抱考拉也是在这边（昆士兰州允许）。
  • 主要是海滩和乐园，景色变化少，四个大人玩7天有点单调。
带小孩或者就想躺着度假时再考虑。
为什么不是「墨尔本进、悉尼出」：也能走，就是推荐路线倒过来。但刚落地就开车上大洋路比较累；把自驾放在中间，前三天先适应左侧通行的路口和环岛（悉尼坐车时多看看），开车会更放心。

行程总览

自驾只在 D4–D6，每天开车不超过3小时，都在天黑前到住处（五月下午5点半左右天黑，傍晚路上容易撞到袋鼠）。点任意一天跳到详情。

请假提醒：2027年五一放假一般是5月1日–5日。5月6日（周四）、7日（周五）大概率要请假；如果5月8日（周六）被调成补班日，也要一起请。这一点和另外两个方案一样，四个人确认好假期再买机票。

D15/1 周六

上海直飞悉尼，落地先吃酸奶，下午逛海港

✈ 约10.5h · 🚆 15分钟住：悉尼要预订：机票、住宿
  • 出发上海浦东 → 悉尼，直飞约10.5小时。

    悉尼比北京 快2小时。选 4/30 晚上或深夜起飞、5/1 早上到的班次：下班直接去机场，机上睡一觉，落地就是一整天。如果只买得到 5/1 晚上起飞的班次，就整体往后挪一天，把 D3 蓝山去掉。

  • 约08:00到悉尼机场。入境卡上「食品」一栏老老实实勾「是」，然后把带的零食给检疫看一眼就行；不申报被查到会当场罚款几百澳元。肉干、蛋黄酥、水果、奶制品都别带。
  • 09:00机场坐火车进城，到 Circular Quay（环形码头）约15分钟。用手机或信用卡 直接刷闸机（Opal 系统支持 Visa/Master 感应支付），不用买卡。
  • 09:45🥛 急头白脸吃酸奶，澳洲分部。码头旁边就有 Woolworths Metro，冷藏柜里找 Jalna、Gippsland Dairy、Five:am 这几个本地牌子，大罐的一公斤装才几澳元。四个人分一罐，拿到歌剧院台阶上开吃，对面就是海港大桥。
  • 10:30酒店寄存行李。步行去 悉尼歌剧院，绕一圈看贝壳屋顶。想进去看就报中文导览（约1小时，官网提前订）。
  • 12:00午饭：岩石区（The Rocks）的老房子里找家酒馆吃炸鱼薯条。周六岩石区有手工市集。
  • 13:30穿过 皇家植物园 走到 麦考利夫人座椅（Mrs Macquarie's Chair），这里是歌剧院和大桥同框的经典机位。
  • 15:00回酒店入住，补觉。第一天别硬撑。
  • 17:15日落。走上 海港大桥 人行道（免费），看歌剧院亮灯。想爬桥顶（BridgeClimb）要提前订，一人约 A$300，可选。
  • 18:30晚饭在岩石区或达令港。超市买好明天早饭。
今天要做的事手机装好 eSIM；四个人建一个分账群；确认信用卡能在闸机上刷（同一张卡一天、一周都有封顶价）。
雨天方案新南威尔士州立美术馆和澳洲博物馆，都免费，离码头都不远。
D25/2 周日

坐轮渡看考拉袋鼠，下午走邦迪海边步道

⛴ 12分钟 · 🚌 约40分钟住：悉尼要预订：动物园门票（网上便宜）
  • 08:45环形码头2号码头坐轮渡去 塔龙加动物园，12分钟，船上回头看歌剧院和大桥。
  • 09:30开门就进。下码头坐 空中缆车（Sky Safari，含在门票里）到山顶入口，然后一路往下逛。重点：考拉、袋鼠和沙袋鼠、鸭嘴兽、袋熊、11点左右的海豹表演。

    新南威尔士州 不能抱考拉，只能近距离看和拍照。

  • 12:30园里吃午饭，坐轮渡回码头。
  • 13:30坐公交 333 路去 邦迪海滩，约40分钟，同样刷卡。今天周日，公共交通全天封顶价很低，随便坐。
  • 14:30邦迪到库吉海边步道（Bondi to Coogee Walk）：全程约6km、2.5–3小时，一路是悬崖、小海湾和海水泳池。走不动就走到勃朗特（Bronte，约2.5km）或克洛夫利（Clovelly）就坐公交回城。
  • 17:15日落。回到邦迪这头的话，去 Icebergs 泳池上面的咖啡馆看海。
  • 18:30回城晚饭。悉尼的中餐、越南粉、泰国菜都很强，Haymarket（唐人街）一带随便选。
注意五月水温约19°C、浪大，下海要在红黄旗之间。这个季节一般只看不游。步道上没遮阳，澳洲紫外线很强，秋天也要涂防晒。
想换个玩法不去动物园的话，从环形码头坐轮渡去 曼利（Manly，30分钟），海滩更安静，船上风景也最好。
D35/3 周一

坐火车去蓝山，看三姐妹峰和峡谷

🚆 单程约2小时住：悉尼要预订：景观世界门票
  • 07:30中央车站（Central）坐 Blue Mountains Line 去 卡通巴（Katoomba），约2小时，同样刷卡。坐右侧（往山上方向）窗外风景好一些，车上没吃的，带早饭。
  • 09:45到站后坐 686 路公交或步行25分钟到 回声角（Echo Point），看 三姐妹峰。早上山谷常有云雾，蓝色最明显。
  • 10:30想走一段的话，下 巨人阶梯（Giant Stairway，约900级台阶）到谷底，再沿步道走到景观世界坐车上来，约1.5–2小时。膝盖不好的就跳过，直接去景观世界。
  • 12:00景观世界（Scenic World）：世界最陡的观光小火车、跨峡谷玻璃底缆车、林间木栈道，一张票都含，玩2小时左右。园区里吃午饭。
  • 14:30公交去 露拉（Leura）小镇，主街很可爱，喝个下午茶。体力好再去 温特沃斯瀑布（Wentworth Falls）看一眼，从车站走过去约20分钟。
  • 16:30从露拉或温特沃斯瀑布站坐火车回悉尼，天黑前出山。
  • 19:00晚饭。今晚收拾行李，明天一早飞墨尔本。
四个人也可以租车悉尼到卡通巴开车约1.5小时，顺路能去 费瑟戴尔野生动物园（Featherdale）喂袋鼠。但悉尼市区停车贵、过路费多，坐火车更省心。
注意山上比悉尼冷5–8°C，带外套。周一部分小店不开门。
D45/4 周二

飞墨尔本取车，开上大洋路，看野生考拉

✈ 1.5h · 🚗 约200km / 3h住：阿波罗湾要预订：国内机票、租车、住宿
  • 07:00悉尼 → 墨尔本，澳航、维珍、捷星都有，约1.5小时，班次很多。选托运行李的票价（捷星最便宜的票不含托运）。
  • 09:00墨尔本机场取车。澳洲靠左行驶，和新西兰一样、和国内相反。四个人加行李租中型 SUV；买零自付的全险；问好加油还是还车时补油。
  • 09:45出发去 托基（Torquay），约1.5小时。路上找个超市买零食和水，顺手再补一罐酸奶。
  • 11:15托基冲浪小镇，贝尔斯海滩（Bells Beach）看冲浪的人。大洋路从这里正式开始。
  • 12:00沿海开，停 大洋路纪念拱门（Memorial Arch）拍照，这条路是一战老兵修的。
  • 13:00罗恩（Lorne）吃午饭。饭后上 Teddy's Lookout 看海湾和公路一起弯过去的样子。
  • 14:30继续往西，到 肯尼特河（Kennett River）拐进 Grey River Road 慢慢开，抬头看桉树上的野生考拉，一般能找到好几只。路边的野生鹦鹉会落到人身上，别喂。
  • 16:00到 阿波罗湾（Apollo Bay）入住。海边散步，天黑前到就行。
  • 18:00晚饭：渔港边的海鲜，龙虾和鲍鱼都是本地的。
开车提醒大洋路很多急弯，一边是悬崖，限速经常变（50–100km/h），中国人多的地段路边有中文提示牌。想停车拍照只能进路边停车点，别直接停在路肩。
谁开车新西兰方案也是自驾，开车的两个人请准备好驾照翻译件，见 自驾须知。
D55/5 周三

穿过雨林，十二门徒石看日落

🚗 约100km（加灯塔约130km）住：坎贝尔港可选：直升机
  • 08:30出发，大洋路从这里离开海边进山，穿过 大奥特威国家公园。
  • 08:50梅茨雨林步道（Maits Rest），一圈30分钟，几百年的山毛榉和蕨树，像侏罗纪。
  • 10:00可选：奥特威角灯塔（Cape Otway Lightstation），要往海边拐一段，来回多40分钟，门票约 A$20。去灯塔的那条路两边桉树上考拉也多。
  • 12:00开到 吉布森台阶（Gibson Steps），走86级台阶下到海滩，站在岩柱脚下抬头看。
  • 12:45十二门徒石 游客中心，走木栈道到观景台。现在只剩7根左右，也一样壮观。旁边小镇或游客中心吃午饭。
  • 14:00往西依次停：洛克阿德峡谷（Loch Ard Gorge，有沉船故事，可以下到沙滩）→ 拱门（The Arch）→ 伦敦拱门（London Arch，原来叫伦敦桥，1990年塌了一半）。每处停20–40分钟。
  • 16:00坎贝尔港（Port Campbell）入住，休息一会儿。
  • 17:00开回十二门徒石观景台（10分钟），等17:30左右的日落，石柱会被照成金色。天黑后回镇上就近吃饭，晚上别再出远门。
直升机十二门徒石游客中心旁边有直升机，10–15分钟一人约 A$150–200，从天上看整段海岸线，四个人一架正好。天气好再现场买。
注意海边风非常大，体感比气温低很多，带防风外套和帽子。袋鼠傍晚出来活动，天黑后尽量不开车。
D65/6 周四

走内陆回墨尔本，下午逛涂鸦巷和拱廊

🚗 约230km / 3h住：墨尔本要预订：住宿
  • 07:00可选：起早去十二门徒石看日出，背光的岩柱和早上没人的观景台，是另一种好看。
  • 09:00退房，走内陆路线（经科拉克 Colac）回墨尔本，约3小时，路直车少，比原路返回快一倍。中途在科拉克休息加油。
  • 12:30市区还车。四个人和行李先打车去酒店，后面两天不用车：墨尔本市中心有 免费电车区，范围内上下车都不用刷卡。
  • 13:30午饭去 Degraves Street，窄巷子里全是咖啡馆，点一杯 flat white，墨尔本人认为这才是全世界最好的咖啡。
  • 14:30走路串起来：霍西尔巷（Hosier Lane）涂鸦 → 联邦广场 → 弗林德斯街车站 → 皇家拱廊和 街区拱廊（Block Arcade）。
  • 16:00维多利亚州立图书馆，免费，上楼看八角形穹顶阅览室，非常出片。
  • 17:30日落去 南岸（Southbank）沿亚拉河散步，或者上 Melbourne Skydeck 看夜景。
  • 19:00晚饭：墨尔本的希腊菜、意大利菜、东南亚菜都很强，Lygon Street 是意大利街。
还车前按合同加满油、拍好车身照片；留意市区的「hook turn」（右转要先靠左等），不熟就直接在机场还车也行，再坐 SkyBus 进城。
雨天方案墨尔本天气一天四季。下雨就去维多利亚国立美术馆（NGV，免费）或墨尔本博物馆。
D75/7 周五

维多利亚市场早午饭，傍晚看小企鹅归巢

🚌 跟团，单程约2h住：墨尔本要预订：企鹅团或企鹅归巢门票
  • 09:00维多利亚女王市场（Queen Victoria Market），周五开门（周一、周三休市）。熟食区买生蚝、芝士、热甜甜圈，奶制品区找找当地农场酸奶。顺便买点伴手礼：麦卢卡蜂蜜、羊毛制品。
  • 11:00自由活动：去 皇家植物园 和 战争纪念馆（Shrine，楼顶能看市区天际线），或者在酒店休息，晚上要很晚回来。

自驾须知只开 D4–D6 三天

新西兰方案开约1300km，这里只开约600km，强度小一半。规矩和新西兰几乎一样。

🪪 驾照和保险

  • 中国驾照 要配英文翻译件才能租车和开车，最常用的是 NAATI 认证翻译（网上办，几天出），或者租车公司认可的公证翻译。中国驾照不能换国际驾照。
  • 主驾一般要满21岁、驾龄满1年，用 主驾本人的信用卡 付押金。
  • 两个人开就登记两个驾驶员，加一个驾驶员一天几澳元。
  • 建议买零自付全险。大洋路上石子、袋鼠都可能刮到车。

🛣 路上规矩

  • 靠左行驶，进环岛让右边来车；驾驶座在右边，雨刷和转向灯也是反的，头一小时常常一打灯就刮雨刷。
  • 测速摄像头很多，超速几公里也罚。乡间限速一般100km/h，镇里50。
  • 黄昏和夜里袋鼠最多，所以行程都安排天黑前到住处。
  • 墨尔本市区有电车，右转有时要走「hook turn」：先停在最左边，等信号再右转。看不懂就跟着前车。

签证和入境

澳洲访客签证（600类）

  • 中国大陆护照要办 旅游签证（Visitor visa subclass 600），在 ImmiAccount 网上申请，费用约 A$200/人。
  • 材料一般要：护照、在职证明（写明准假）、银行流水或存款证明、行程单；有过美加英申根签证的，附上更容易。
  • 可能会被要求去签证中心录指纹，审批一般2–4周，建议2027年1–2月申请，五一前留足时间。
  • 不需要先订机票酒店，但有行程单更好。

其他

  • 入境检疫很严：所有食品、药品如实申报。肉类、蛋、奶制品、新鲜水果、种子都不能带，带了没申报会罚款甚至取消签证。
  • 插头是 I 型（八字形扁脚），国内的三脚插头大多能直接插；两脚扁插头需要转换。电压230V。
  • 澳元，几乎处处可以刷卡和手机支付，有的店刷卡加收1–2%手续费。不用给小费。
  • 护照在入境时要有6个月以上有效期。
