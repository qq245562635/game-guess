这条线适合谁B · 墨尔本进出 + 塔斯马尼亚自驾

塔斯马尼亚是澳洲南边的一个岛，一半是国家公园。五月初正好是 落叶山毛榉变金黄 的季节，人少，路好开，海鲜便宜。风景和新西兰南岛很像：雪山、湖、海湾、野生动物，只是规模小一些。

适合：喜欢自驾、徒步和野生动物；想要新西兰那种风景，但飞行时间短、只有2小时时差；想吃生蚝。
要接受：岛上冷（山里可能下雪）；没有大城市；上海不能直飞，要在墨尔本转一次；如果最后选了新西兰，这条线就重复了。

行程总览

墨尔本进出，岛上一圈：霍巴特 → 东海岸 → 朗塞斯顿 → 摇篮山，自驾6天约850km，每天最多开3小时，都在天黑前到住处。

D15/1 周六

上海直飞墨尔本，落地吃酸奶，下午逛市中心

✈ 约11h住：墨尔本要预订：机票、住宿
  • 出发上海浦东 → 墨尔本，直飞约11小时。

    墨尔本比北京 快2小时。选 4/30 晚上起飞、5/1 早上到的班次，下班直接去机场。往返都是墨尔本，机票比开口程好买、也更便宜。

  • 约08:30到墨尔本机场。入境卡上「食品」一栏如实勾「是」，肉、蛋、奶、水果都别带。
  • 09:30SkyBus 进城到南十字星站，约30分钟。
  • 10:15🥛 急头白脸吃酸奶，塔斯马尼亚线。市中心随便一家 Coles 或 Woolworths，找 Jalna（就是墨尔本本地牌子）和 Gippsland Dairy，大罐四个人分。
  • 11:00酒店寄存行李。在 免费电车区 里坐电车，逛 Degraves Street 咖啡巷、霍西尔巷涂鸦、弗林德斯街车站。
  • 13:00午饭。周六 维多利亚女王市场 开门，吃热甜甜圈和生蚝。
  • 14:30回酒店入住，补觉。
  • 17:30日落时去南岸沿亚拉河散步，晚饭吃意大利菜或希腊菜。早睡，明天一早飞霍巴特。
今天要做的事手机装好 eSIM；四个人建分账群；把塔斯马尼亚国家公园通行证（Parks Pass）在网上买好。
为什么先在墨尔本住一晚国际航班落地后再转国内航班，行李要重新托运，时间很紧。先住一晚，第二天一早飞，最稳。
D25/2 周日

飞霍巴特取车，惠灵顿山顶看全城

✈ 1.3h · 🚗 约50km住：霍巴特要预订：国内机票、租车
  • 07:30墨尔本 → 霍巴特，约1小时15分。澳航、维珍、捷星都有。
  • 09:30霍巴特机场取车，霍巴特取、朗塞斯顿还（岛内异地还车一般不加钱或加得很少，订的时候确认）。四个人加行李租中型 SUV。
  • 10:30进城寄存行李，逛 萨拉曼卡广场（Salamanca Place）的砂岩老仓库，现在都是画廊和咖啡馆。周六的大集市今天没有，但店铺开门。
  • 12:00午饭在港口吃 炸鱼薯条，霍巴特码头的海上餐车很有名。
  • 13:30开车上 惠灵顿山（kunanyi / Mt Wellington）山顶，海拔1271米，约30分钟盘山路。整个霍巴特、德文特河和海湾都在脚下。山顶风极大，常有雪，穿最厚的衣服。
  • 15:30下山逛 炮台角（Battery Point）的老街小屋。
  • 17:00天黑前回酒店。晚饭吃塔斯马尼亚生蚝和三文鱼，便宜又新鲜。
想看艺术MONA 古今艺术博物馆：从码头坐船去，很前卫，有些展品尺度很大。开放日不固定，去之前查官网。时间不够可以放在 D3 晚上之前或者跳过。
注意塔斯马尼亚比墨尔本冷，五月白天10–15°C，山顶可能零下。
D35/3 周一

塔斯曼半岛：亚瑟港监狱遗址和海边奇石

🚗 来回约200km住：霍巴特要预订：亚瑟港门票
  • 08:30出发去 亚瑟港（Port Arthur），约1.5小时。
  • 09:30路上先停 镶嵌路面（Tessellated Pavement），海边的岩石天然裂成一块块方砖，退潮时最清楚。
  • 10:00塔斯曼拱门（Tasman Arch）和 魔鬼厨房（Devils Kitchen），都在路边，各停15分钟。
  • 10:45亚瑟港历史遗址：19世纪的流放犯监狱，世界遗产。门票含20分钟游船和导览，园区很大，逛3小时左右。
  • 13:30园区里吃午饭。
  • 14:30可选：Remarkable Cave（10分钟车程），从海蚀洞里看出去的海是一个塔斯马尼亚岛的形状。
  • 15:30回霍巴特，天黑前到。
  • 18:00晚饭。超市买好明天路上的零食。
晚上可选亚瑟港有 夜间鬼故事导览（Ghost Tour），但结束后要开1.5小时夜路，路上袋鼠、袋熊很多，不推荐。
注意半岛上几乎没有信号死角，但加油站少，出发前在霍巴特加满油。
D45/4 周二

看袋獾和袋熊，沿东海岸到菲欣纳国家公园

🚗 约200km / 3h住：科尔斯湾要预订：保护区导览、住宿
  • 08:30退房，往北开30分钟到 博诺朗野生动物保护区（Bonorong）。
  • 09:00跟园区导览看 袋獾（塔斯马尼亚恶魔）、袋熊，可以自己喂袋鼠。这里是救助中心，动物都是被救回来的。
  • 11:00上东海岸公路（Tasman Highway）。路过 斯旺西（Swansea）时停 荆棘桥（Spiky Bridge），流放犯用石头垒的，桥栏上全是竖起来的尖石。
  • 12:30午饭：Kate's Berry Farm，草莓松饼和莓果冰淇淋。
  • 14:00到 科尔斯湾（Coles Bay）入住。菲欣纳国家公园（Freycinet）就在旁边，Parks Pass 要挂在车里。
  • 15:30开到 图维尔角灯塔（Cape Tourville），10分钟木栈道，能看到整片海岸。
  • 17:00蜜月湾（Honeymoon Bay）看日落，粉红色的花岗岩配夕阳。
  • 18:00晚饭：去 Freycinet Marine Farm 吃现开的生蚝和贻贝（下午就关门的话就镇上吃）。
注意东海岸公路弯多，两边常有被撞的动物。天黑前一定要到科尔斯湾。
小镇很小科尔斯湾只有一家小超市，晚饭和第二天早饭提前准备。
D55/5 周三

爬上酒杯湾观景台，下午到朗塞斯顿

🚗 约180km / 2.5h住：朗塞斯顿徒步约1.5小时
  • 08:00酒杯湾观景台（Wineglass Bay Lookout）：从停车场上山，来回约1–1.5小时，坡有点陡但都是台阶。从山口往下看，就是那个酒杯形状的海湾。
  • 09:30体力好可以继续下到 酒杯湾沙滩，来回再加1.5–2小时，沙子白得发亮。不下去就直接回停车场。
  • 11:00退房出发去 朗塞斯顿（Launceston），走内陆，约2.5小时。
  • 13:30朗塞斯顿午饭。
  • 14:30卡塔拉克特峡谷（Cataract Gorge），离市中心走路15分钟：坐世界最长单跨缆椅过峡谷，看孔雀，峡谷步道散步。
  • 16:30入住。逛市中心的维多利亚式老建筑。
  • 18:30晚饭。这一带是塔斯马尼亚的葡萄酒产区，能喝的点一杯黑皮诺。
不想爬山酒杯湾也可以坐游船从海上看（约4小时），但五月班次少，提前查。
补给朗塞斯顿是北部最大的城市，明天进山前在这里买好吃的和水，摇篮山上东西又少又贵。
D65/6 周四

摇篮山：鸽子湖一圈，找金色的落叶山毛榉

🚗 约145km / 2h住：摇篮山要预订：住宿（最难订）
  • 08:00出发去 摇篮山（Cradle Mountain），约2小时，最后一段是山路。
  • 10:00到游客中心停车，换乘公园穿梭巴士进山（私家车不能开到鸽子湖），Parks Pass 含车票。
  • 10:30鸽子湖环线（Dove Lake Circuit）：6km、约2–3小时，平路木栈道为主，全程绕着摇篮山走，一定要在老船屋前拍一张。
  • 13:30午饭（自带或游客中心咖啡馆）。
  • 14:30找落叶山毛榉（Fagus）：这是澳洲唯一会变色的原生树，每年4月底到5月中金黄，叫 Turning of the Fagus。从湖边往火山口湖（Crater Lake）方向走一段就能看到成片的金色，看到哪算哪。
  • 16:30入住山里的木屋。
  • 17:00朗尼溪（Ronny Creek）木栈道，傍晚野生袋熊出来吃草，几米远都不怕人。
  • 18:30木屋里做饭或去山庄餐厅。晚上看星星。
天气摇篮山一年里有大半时间在下雨或起雾，五月可能下雪。没看到山顶也正常，湖边的雨林一样好看。
落叶山毛榉颜色每年早晚不同，5月初通常还在，但如果那年变色早，可能已经过了高峰。出发前一周搜 "Fagus Cradle Mountain" 看最新照片。
D75/7 周五

早上再看袋熊，经过壁画小镇，飞回墨尔本

🚗 约150km / 2h · ✈ 1h住：墨尔本要预订：朗塞斯顿 → 墨尔本机票
  • 07:30起早再去朗尼溪或木屋附近的 魔法步道（Enchanted Walk，20分钟），早上动物也多。
  • 09:30出发，路过 谢菲尔德（Sheffield）壁画小镇，房子墙上画满了大壁画，停半小时。
  • 11:30可选：Ashgrove 奶酪厂、Christmas Hills 覆盆子农场，就在去机场的路上，奶酪厂里有本地酸奶。
  • 13:30朗塞斯顿机场还车。加满油、拍车身照片。
  • 15:00朗塞斯顿 → 墨尔本，约1小时。
  • 17:00到墨尔本，SkyBus 进城入住。晚饭去 Lygon Street 或唐人街。
为什么从朗塞斯顿飞不用开回霍巴特（多3小时），朗塞斯顿飞墨尔本班次也多。
如果想多玩一天把 D8 的航班改成 5/8 深夜起飞、5/9 早上到，5/8 白天还能在墨尔本逛半天。
D85/8 周六

墨尔本 brunch，飞回上海

🚌 SkyBus 30分钟 · ✈ 约11h住：家里
  • 08:00墨尔本 brunch：牛油果吐司、班尼迪克蛋。周六咖啡馆要排队，早点去。
  • 09:00南十字星站坐 SkyBus 去机场。
  • 10:00到机场。买满 A$300 的可以办退税（TRS），提前在 App 里填好。
  • 中午前后墨尔本直飞上海，约11小时，晚上到浦东。
  • 5/9 周日在家休息一天，5/10 周一正常上班。
伴手礼塔斯马尼亚的薰衣草熊、蜂蜜、三文鱼罐头都可以在机场买；新鲜水果和肉别带回国。
酸奶善后没吃完的大罐酸奶带不上飞机，早饭就地解决。

岛上自驾须知

🪪 驾照和车

  • 中国驾照 + NAATI 英文翻译件，主驾本人信用卡付押金，和方案 A 一样。
  • 霍巴特取、朗塞斯顿还，订车时确认异地还车费。
  • 买零自付全险。岛上很多碎石路段，挡风玻璃容易被石子打到。

🦘 路上

  • 塔斯马尼亚的路边动物尸体比澳洲任何地方都多，黄昏后不开车。
  • 山路窄、弯多，限速常常是80或更低；摇篮山附近可能结冰。
  • 国家公园要买 Parks Pass（按车，Holiday Pass 两个月有效），网上买、打印或存手机。
